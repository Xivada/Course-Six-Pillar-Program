# Assessments: Quizzes & Certification Exam

## Knowledge Review Quiz (Sample)
- **Q**: What is the primary function of the PAUSE framework?
  - **A**: Structured, five-step decision-making process for counselors.
- **Q**: Which brain region is the "Command Center Under Construction"?
  - **A**: Prefrontal Cortex (PFC).
- **Q**: What does the 'A' in SOAR stand for?
  - **A**: Analysis.

## Written Certification Exam Structure
- **Part I: Multiple Choice (40%)**: Six pillars, PFC development, Texas Family Code (Section 261).
- **Part II: Crisis Response (30%)**: Write progress note (SOAR) and incident report for a "Red Flag" scenario.
- **Part III: Essay (30%)**: 500-word reflection on facilitation style and growth.
